Task: Refactor the "Deploy" Dashboard UI for Admin and Project Manager Users.

Context: We are upgrading the current dashboard from a basic utility interface to a professional, high-density SaaS command center. The target audience is Administrators and Project Managers. Their goal is governance, identifying bottlenecks, and monitoring system health—not just viewing a personal to-do list.

Design System & Styling:

Vibe: Clean, "Enterprise SaaS," high efficiency.

Palette: Switch from the current "rainbow" buttons to a Monochromatic/Duotone Blue theme. Use light grays (bg-gray-50 or #F4F6F8) for the page background and White for cards.

Shadows: Soft, diffused shadows (shadow-sm or shadow-md) for depth. No heavy borders.

Typography: Strict hierarchy. Dark headers, lighter subtext. Use "Inter" or similar sans-serif.

Specific Implementation Steps:

Layout: 4 cards in a flex/grid row.

Features: Title (uppercase, small), Main Value (large, bold), Icon (top right, subtle), and a Footer for Context/Trends.

Data Points to Mock:

Pending Approvals: Value "8", Alert style (red border left), Subtext "Requires review".

Avg Resolution Time: Value "4.2h", Trend "12% (Green Arrow Up)", Subtext "vs last week".

Active Staff: Value "14", Subtext "3 currently idle".

Critical Issues: Value "3", Trend "2 (Red Arrow Down)", Subtext "High priority".
